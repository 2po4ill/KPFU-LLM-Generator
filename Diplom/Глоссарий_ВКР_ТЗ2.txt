ГЛОССАРИЙ

Python — язык программирования, на котором реализованы серверная часть сервиса, обработка документов и вызовы языковых моделей.
FastAPI — веб-фреймворк для построения асинхронного HTTP API и описания эндпоинтов загрузки РПД, книг и генерации материалов.
PostgreSQL — реляционная СУБД для хранения структурированных данных запросов, отпечатков обращений и сгенерированного контента.
Redis — хранилище в оперативной памяти, используемое для кэширования и ограничения нагрузки на тяжёлые операции.
LLM (Large Language Model) — крупная языковая модель, применяемая для извлечения структуры из текста РПД, выбора страниц по оглавлению и генерации учебных текстов.
Ollama — среда локального запуска языковых моделей (инференс LLM) без внешних облачных вызовов.
PyMuPDF и pdfplumber — библиотеки извлечения текста из PDF-файлов учебников и учебно-методических документов.
Telegram-бот — клиентский интерфейс в мессенджере Telegram, обеспечивающий пошаговую работу пользователя с сервисом без прямого обращения к API.
Moodle — система управления обучением (LMS), в которую планируется импорт сгенерированных материалов.
SCORM — стандарт упаковки электронных учебных курсов для загрузки в LMS и просмотра в браузере обучаемого.
ChromaDB — векторное хранилище для эмбеддингов фрагментов текста при семантическом поиске и сопоставлении утверждений с источником.
Sentence Transformers — семейство моделей, формирующих векторные представления текста для оценки семантической близости фрагментов.
API (Application Programming Interface) — набор программных правил и эндпоинтов HTTP, по которым клиенты взаимодействуют с сервисом.
РПД (рабочая программа дисциплины) — нормативный документ, задающий содержание дисциплины, тематику занятий и ожидаемые результаты обучения.
Оглавление (TOC) — перечень разделов и подразделов учебника с указанием номеров страниц, используемый для выбора релевантных фрагментов источника.
Смещение нумерации страниц — разница между номером страницы в оглавлении или колонтитуле книги и порядковым номером страницы в файле PDF, подлежащая учёту при извлечении текста.
Пайплайн — последовательность этапов обработки: извлечение данных из РПД, подготовка источников, генерация материала, верификация и оформление результата.
Кэширование — сохранение промежуточных результатов (оглавление, параметры смещения, извлечённые страницы) для ускорения повторных запросов.
Батч — партия страниц или фрагментов, обрабатываемая за один проход при вызове языковой модели или при пакетной обработке данных.
Эмбеддинг (векторное представление текста) — числовой вектор, кодирующий смысл фрагмента текста и применяемый для сравнения утверждений с содержимым страниц учебника.
Семантическая сходимость — мера близости векторов эмбеддингов, используемая при проверке соответствия утверждения фрагментам источника.
Сокосинусное сходство — конкретная метрика близости векторов при сопоставлении текста утверждения и текста страницы учебника.
Порог сходимости — заранее заданное граничное значение метрики, выше которого утверждение считается подтверждённым выбранным фрагментом источника.
Верификация — процесс проверки того, что фактические утверждения в сгенерированном тексте согласуются с содержимым реально использованных страниц учебника.
Извлечение утверждений — выделение из сгенерированного текста проверяемых формулировок для последующего сопоставления с источником.
Оценка уверенности — числовой показатель, отражающий долю утверждений, признанных подтверждёнными источником в ходе верификации.
Антигаллюцинация — совокупность приёмов снижения риска недостоверного содержания за счёт опоры на источник, ограничения контекста и автоматической проверки утверждений.
Генерация учебных материалов — автоматическое формирование текстов лекций, лабораторных и практических работ по структуре РПД и содержанию учебной литературы.
Валидация данных РПД — проверка полноты и допустимости полей, извлечённых из документа РПД, перед запуском генерации.
Форматирование по шаблону ФГОС — приведение итогового текста к структуре с указанием дисциплины, направления подготовки и учебно-методических реквизитов.
Чанк — фрагмент текста фиксированной длины, на который может разбиваться книга для векторного индексирования и поиска.
Лабораторная работа — вид учебного материала с практическим заданием по теме дисциплины, формируемый в соответствии с РПД.
Практическое занятие — учебный материал, ориентированный на отработку навыков по теме при подготовке к лабораторным работам и контролю.
Запрос к языковой модели — текст инструкции и контекста, передаваемый в LLM для извлечения данных из РПД или для генерации учебного текста.
Объект исследования — процесс автоматизированной подготовки учебных материалов по рабочей программе дисциплины с использованием средств обработки документов и генеративных моделей.
Предмет исследования — методы и программные решения сервиса: извлечение структурированных данных из РПД, выбор страниц учебника, генерация материалов, их верификация и оформление результата.
Актуальность — обоснование значимости темы исследования для образовательной практики и области программной инженерии.
