Краткие пояснения:

* Система RSA — это система шифрования с открытым ключом, в которой используются два разных ключа: открытый (public) для шифрования и секретный (private) для расшифрования.
* Вычет — это класс эквивалентности, образованный целыми числами по отношению сравнения по модулю n.
* Расширенный алгоритм Евклида используется в методе RSA для вычисления обратной величины.
