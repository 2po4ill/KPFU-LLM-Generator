# RSA

Введение в систему шифрования RSA.

Система шифрования RSA представляет собой метод защиты информации, при котором для шифрования и расшифрования используются совершенно разные ключи. Ключ шифрования, используемый для преобразования исходного текста в шифротекст, разрешается передавать любому пользователю системы, не задумываясь о безопасности, поэтому этот ключ называется открытым – public. В отличие от этого, секретный ключ, который используется для восстановления исходного текста, должен быть сохранен конфиденциально.

Метод RSA является примером систем шифрования с открытым ключом и использует сложение и умножение больших чисел для генерации ключей шифрования и расшифрования. Ключ шифрования в методе RSA представляет собой большое число, которое можно разделить на два других числа: n и e. Ключ расшифрования представляет собой другое большое число, которое можно разделить на два других числа: n и d.

Система шифрования RSA обеспечивает безопасность алгоритма за счет неразрешимости факторизации большого числа на простые множители. Это

### Системы шифрования с открытым ключом
<!-- CONCEPT_ORIGIN: concept="Системы шифрования с открытым ключом"; pages=[15,16,17,18,19]; book=""; claims=[{"text": "[нет извлеченных утверждений]", "page": 0}] --> <!-- REVIEW_NOTE="missing_origin" -->

Системы шифрования с открытым ключом представляют собой методы защиты информации, при которых для шифрования и расшифрования используются совершенно разные ключи. Ключ шифрования, используемый для преобразования исходного текста в шифротекст, разрешается передавать любому пользователю системы, не задумываясь о безопасности, поэтому этот ключ называется открытым – public. В отличие от этого, секретный ключ, который используется для восстановления исходного текста, должен быть сохранен конфиденциально.

#### Определения

- **Открытый ключ**: Ключ шифрования, используемый для преобразования исходного текста в шифротекст.
- **Секретный ключ**: Ключ расшифрования, используемый для восстановления исходного текста.
- **Модуль**: Натуральное число, по которому выполняются арифметические операции.

#### Механизм

1.  Генерация ключей: Сначала генерируются два больших простых числа p и q. Затем вычисляется n = p \* q.
2.  Вычисление открытого ключа: Вычисляется e такое, что e и (p-1) взаимно простые.
3.  Вычисление секретного ключа: Вычисляется d такое, что d \* e ≡ 1( mod (p-1)\*q).
4.  Шифрование: Используется открытый ключ для преобразования исходного текста в шифротекст по формуле c ≡ m^e( mod n).
5.  Расшифрование: Используется секретный ключ для восстановления исходного текста по формуле m ≡ c^d( mod n).

#### Практический пример

-   Например, если мы хотим зашифровать сообщение "HELLO", используя открытый ключ (e = 3, n = 77), то получаем c ≡ h^3( mod 77).
-   Чтобы расшифровать сообщение, мы используем секретный ключ (d = 23) и вычисляем m ≡ c^23( mod 77).

#### Типичные ошибки/ограничения

-   **Недостаточная безопасность**: Если открытый или секретный ключ слишком мал, то система шифрования может быть взломана.
-   **Неправильное использование**: Если пользователь неправильно использует систему шифрования, например, не сохраняя секретный ключ в безопасности, то система может быть взломана.

### Модулярная арифметика

Модулярная арифметика — это область математики, которая изучает свойства целых чисел по модулю некоторого натурального числа. В методе RSA используется модуль p, который является простым числом. Ключ шифрования в методе RSA представляет собой число e такое, что e и (p-1) взаимно простые.

#### Определения

-   **Модуль**: Натуральное число, по которому выполняются арифметические операции.
-   **Взаимная простота**: Числа a и b являются взаимно простыми, если их наибольший общий делитель равен 1.

#### Механизм

1.  Вычисление остатка: Для любых целых чисел a и n вычисляется остаток от деления a на n по формуле a mod n = a - (a/n) \* n.
2.  Выполнение арифметических операций: Над целыми числами можно выполнять сложение, вычитание, умножение и возведение в степень.

#### Практический пример

-   Например, если мы хотим найти остаток от деления числа 17 на 5, то получаем 17 mod 5 = 2.

#### Типичные ошибки/ограничения

-   **Неправильное использование**: Если пользователь неправильно использует модулярную арифметику, например, не учитывая взаимную простоту чисел, то система может быть взломана.

Криптографические свойства метода RSA — это набор свойств, которые обеспечивают безопасность алгоритма. Основным криптографическим свойством является неразрешимость факторизации большого числа на простые множители. Это означает, что для расшифровки сообщения необходимо иметь секретный ключ, который невозможно получить из открытого ключа.

Неразрешимость факторизации связана с тем, что RSA использует большие целые числа, которые сложно разбить на простые множители. Для этого требуется значительное время и мощность вычислений. Это свойство обеспечивает безопасность алгоритма, поскольку даже если атакующий имеет доступ к открытому ключу, он не сможет факторизовать большое число и получить секретный ключ.

Примером использования неразрешимости факторизации является следующая задача: предположим, что у нас есть публичный ключ 3233 (который представляет собой произведение двух простых чисел p и q). Если атакующий попытается факторизовать это число, он столкнется с проблемой неразрешимости факторизации. Для этого требуется значительное время и мощность вычислений.

### Алгоритмы, используемые в методе RSA

Алгоритмы, используемые в методе RSA, включают в себя алгоритм Евклида и алгоритм расширенного Евклида. Основным алгоритмом является алгоритм Евклида, который используется для нахождения наибольшего общего делителя (НОД) двух чисел.

Алгоритм Евклида работает следующим образом: он использует рекурсивный процесс, в котором два числа делятся пополам и результаты сравниваются. Если остаток равен нулю, то НОД находится. В противном случае процесс повторяется с новыми числами.

Алгоритм расширенного Евклида используется для нахождения обратной матрицы. Он работает аналогично алгоритму Евклида, но вместо нахождения НОД он находит обратную матрицу.

Примером использования алгоритма Евклида является следующая задача: предположим, что у нас есть два числа 17 и 23. Алгоритм Евклида используется для нахождения НОД этих чисел. Результатом будет число 1, которое представляет собой НОД.
