# Лабораторная работа: RSA

**Цель работы**
Ознакомиться с основными принципами и алгоритмами метода RSA, используемого в системах шифрования с открытым ключом.

**Краткая теоретическая база**

Системы шифрования с открытым ключом представляют собой класс криптографических протоколов, которые используют два разных ключа: открытый (public) и секретный (private). Ключ шифрования, используемый для преобразования исходного текста в шифротекст, разрешается передавать любому пользователю системы, не задумываясь о безопасности. В отличие от этого, секретный ключ используется только для восстановления исходного текста.

Метод RSA является одним из наиболее широко используемых алгоритмов систем шифрования с открытым ключом. Он основан на использовании модулярной арифметики и использует принципы теории чисел для обеспечения безопасности.

**Необходимые данные/инструменты**

* Понимание основных принципов модулярной арифметики
* Знания по теории чисел, в частности, понятие простых чисел и их свойств

**Пошаговое выполнение**

1. **Шифрование**: Используя открытый ключ, преобразуйте исходный текст в шифротекст с помощью алгоритма RSA.
2. **Дешифрование**: Используя секретный ключ, восстановите исходный текст из шифротекста.
3. **Верификация**: Проверьте корректность работы алгоритма RSA, используя проверочную сумму или другой метод.

**Ожидаемые результаты**

* Правильное шифрование и дешифрование исходного текста с помощью алгоритма RSA.
* Верификация правильности работы алгоритма RSA.

**Критерии оценивания**

* Правильность понимания основных принципов метода RSA
* Правильность выполнения шифрования, дешифрования и верификации
* Качество и четкость представленной информации

**Типичные ошибки**

* Неправильное использование открытого или секретного ключа.
* Неправильная реализация алгоритма RSA.
* Недостаточное понимание модулярной арифметики и теории чисел.
