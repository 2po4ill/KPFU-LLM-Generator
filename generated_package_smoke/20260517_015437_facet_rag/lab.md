# Лабораторная работа: RSA

**Цель работы**
Оценить понимание алгоритма RSA и его основополагающих принципов.

**Краткая теоретическая база**

Алгоритм RSA относится к системам шифрования с открытым ключом. Он использует два разных ключа: открытый (public) и секретный (private). Открытый ключ используется для шифрования, а секретный ключ — для расшифрования.

**Необходимые данные/инструменты**

* Пара простых чисел p и q
* Открытый ключ (e)
* Секретный ключ (d)

**Пошаговое выполнение**

1. **Шифрование**: Используя открытый ключ e, преобразуйте исходную информацию m в шифротекст c по формуле: c ≡ m^e (mod n), где n = p \* q.
2. **Расшифрование**: Используя секретный ключ d, преобразуйте шифротекст c обратно в исходную информацию m по формуле: m ≡ c^d (mod n).

**Ожидаемые результаты**

* Правильное шифрование и расшифрование информации с использованием алгоритма RSA.
* Понимание роли открытого и секретного ключей в алгоритме.

**Критерии оценивания**

* Правильность понимания основополагающих принципов алгоритма RSA.
* Успешное выполнение шифрования и расшифрования с использованием алгоритма RSA.
* Понимание роли открытого и секретного ключей в алгоритме.

**Типичные ошибки**

* Неправильное понимание роли открытого и секретного ключей.
* Неправильная реализация шифрования или расшифрования.
* Неправильное использование формул для шифрования и расшифрования.
