# Лабораторная работа: RSA

**Цель работы**
Оценить понимание алгоритма RSA и его основополагающих принципов.

**Краткая теоретическая база**

Алгоритм RSA относится к системам шифрования с открытым ключом, в которых для шифрования и расшифрования используются совершенно разные ключи. Ключ шифрования (публичный ключ) разрешается передавать любому пользователю системы, а секретный ключ используется только для восстановления исходного текста.

Модулярная арифметика является фундаментальным понятием в алгоритме RSA. Операции над вычетами по модулю выполняются как над обычными числами, приводя результат к значению, принадлежащему интервалу [0, n−1].

**Необходимые данные/инструменты**

* Публичный ключ (e)
* Секретный ключ (d)
* Модуль (n), который является произведением двух больших простых чисел p и q
* Основание (φ(n)), которое представляет собой функцию Эйлера

**Пошаговое выполнение**

1. **Шифрование**: преобразуйте исходный текст в шифротекст, используя публичный ключ e и модуль n: c ≡ m^e (mod n)
2. **Расшифрование**: восстановите исходный текст из шифротекста, используя секретный ключ d и модуль n: m ≡ c^d (mod n)

**Ожидаемые результаты**

* Шифротекст должен быть нечитаемым и неавторизированным.
* Расшифрование должно привести к восстановлению исходного текста.

**Критерии оценивания**

* Правильность понимания алгоритма RSA и его основополагающих принципов
* Правильность выполнения шифрования и расшифрования
* Качество и четкость представления результатов

**Типичные ошибки**

* Неправильное использование публичного или секретного ключа.
* Неправильная работа с модулем n и основанием φ(n).
* Неправильное представление результатов.
