# Лабораторная работа: RSA

**Цель работы**
Ознакомиться с алгоритмом RSA и его основными свойствами.

**Краткая теоретическая база**

Системы шифрования с открытым ключом представляют собой класс криптографических методов, в которых для шифрования и расшифрования используются разные ключи. Ключ шифрования (открытый ключ) разрешается передавать любому пользователю системы, а секретный ключ используется только для восстановления исходного текста.

Модулярная арифметика — это область математики, которая изучает свойства целых чисел по модулю натурального числа. В частности, мы будем использовать понятие сравнения по модулю, которое определяется следующим образом: два целых числа a и b сравнимы по модулю p (a ≡ b(mod p)), если p делит разность a − b.

**Необходимые данные/инструменты**

* Основные понятия модулярной арифметики
* Определение системы шифрования с открытым ключом

**Пошаговое выполнение**

1. Ознакомьтесь с основными свойствами систем шифрования с открытым ключом.
2. Понаблюдайте за определением сравнения по модулю и его свойствами.
3. Изучите алгоритм RSA и его основные компоненты: открытый ключ, секретный ключ и функция шифрования.

**Ожидаемые результаты**

* Ознакомление с основными свойствами систем шифрования с открытым ключом
* Понимание определения сравнения по модулю и его свойств
* Изучение алгоритма RSA и его компонентов

**Критерии оценивания**

* Правильность понимания основных свойств систем шифрования с открытым ключом
* Правильность определения сравнения по модулю и его свойств
* Правильность изложения алгоритма RSA и его компонентов

**Типичные ошибки**

* Неправильное понимание основных свойств систем шифрования с открытым ключом
* Неправильное определение сравнения по модулю и его свойств
* Неправильное изложение алгоритма RSA и его компонентов
