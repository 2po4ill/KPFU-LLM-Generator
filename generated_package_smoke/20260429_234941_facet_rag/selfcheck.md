**Краткие пояснения**

* Система шифрования с открытым ключом — это система, в которой используется открытый ключ для шифрования и секретный ключ для расшифрования.
* Модулярная арифметика — это арифметика с использованием модулей для представления чисел.
* Отношение сравнения по модулю имеет свойства рефлексивности, симметричности и транзитивности.
* Вычет в контексте модулярной арифметики — это число, которое делится на модуль без остатка.
* Кольцо с операциями сложения и умножения образует множество классов вычетов по модулю n.
