# Лабораторная работа: RSA

**Цель работы**
Ознакомиться с алгоритмом RSA и его основными свойствами.

**Краткая теоретическая база**

Система шифрования с открытым ключом — это метод шифрования, при котором для шифрования и расшифрования используются совершенно разные ключи. Ключ шифрования (публичный ключ) разрешается передавать любому пользователю системы, а секретный ключ используется только для восстановления исходного текста.

Модулярная арифметика — это область математики, которая изучает операции с целыми числами по модулю некоторого числа. В частности, мы будем использовать следующие свойства:

* Рефлексивность: a ≡ a (mod p)
* Симметричность: a ≡ b (mod p) → b ≡ a (mod p)
* Транзитивность: a ≡ b (mod p) и b ≡ c (mod p) → a ≡ c (mod p)

**Необходимые данные/инструменты**

* Публичный ключ (e, n), где e — экспонента, а n — модуль
* Секретный ключ (d, n), где d — обратная экспонента

**Пошаговое выполнение**

1. **Шифрование**: для шифрования сообщения m мы вычисляем c ≡ m^e (mod n)
2. **Расшифрование**: для расшифрования сообщения c мы вычисляем m ≡ c^d (mod n)

**Ожидаемые результаты**

* Шифрованный текст c должен быть неотличим от случайного числа.
* Расшифрованный текст m должен совпадать с исходным текстом.

**Критерии оценивания**

* Правильность шифрования и расшифрования
* Скорость выполнения алгоритма

**Типичные ошибки**

* Неправильное использование публичного или секретного ключа.
* Неправильная реализация модулярной арифметики.

**Примечания**

* В этом задании мы не будем учитывать безопасность алгоритма и защиту от атак.
