# RSA

**Введение. Криптография с открытым ключом и модулярная арифметика**

Криптография — это область математики, которая занимается защитой информации от несанкционированного доступа. Системы шифрования с открытым ключом являются важнейшим направлением в криптографии. В этом конспекте будут рассмотрены основные концепции системы RSA и модулярной арифметики, которые лежат в основе этих систем.

**Системы шифрования с открытым ключом**

Система шифрования с открытым ключом использует два разных ключа: открытый ключ (public key) и закрытый ключ (private key). Открытый ключ используется для шифрования сообщений, а закрытый ключ — для расшифрования их обратно. Это позволяет пользователям обмениваться секретной информацией без риска ее перехвата.

**Модулярная арифметика**

Модулярная арифметика — это область математики, которая изучает операции с целыми числами по модулю некоторого числа. Пусть Z обозначает множество целых чисел. В системе RSA используется модуль p, который является большим простым числом.

**Кольца**

Кольцом K называется непустое множество элементов, на котором определены две арифметические операции сложения + и умножения ·. В системе RSA кольцо Zp представляет собой множество целых чисел по модулю p.

В этом конспекте будут раскрыты основные концепции системы RSA и модулярной арифметики, которые лежат в основе этих систем. Это позволит читателям понять принципы работы систем шифрования с открытым ключом и применение модулярной арифметики в криптографии.

## Основные концепции

**Основные концепции: RSA**

### Системы шифрования с открытым ключом

Система шифрования с открытым ключом — это тип криптографических систем, в которых для шифрования и расшифрования используются совершенно разные ключи. Ключ шифрования, используемый для преобразования исходного текста в шифротекст, разрешается передавать любому пользователю системы, не задумываясь о безопасности, поэтому этот ключ называется открытым – public. В отличие от этого, секретный ключ, используемый для восстановления исходного текста, должен быть сохранен конфиденциально.

Примером такой системы является система RSA. Система RSA использует два разных ключа: открытый ключ (public key) и закрытый ключ (private key). Открытый ключ используется для шифрования сообщений, а закрытый ключ — для расшифрования их обратно.

### Модулярная арифметика

Модулярная арифметика — это область математики, которая изучает операции с целыми числами по модулю некоторого числа. Пусть Z обозначает множество целых чисел. Все рассматриваемые в нашем учебнике числа, если не указано особо, принадлежат Z.

Определение 2.1: Говорят, что два целых числа a и b сравнимы по модулю p, записывается, a ≡ b( mod p), если p|(a − b) (разность a − b делится на p без остатка). Отношение сравнения по модулю натурального числа обладает следующими свойствами: 1. Рефлексивность: a ≡ a( mod p). 2. Симметричность: a ≡ b( mod p) → b ≡ a( mod p). 3. Транзитивность: a ≡ b( mod p)&b ≡ c( mod p) → a ≡ c( mod p).

Например, если мы хотим проверить, равны ли числа 17 и 23 по модулю 5, мы можем вычислить разницу между ними: 17 - 23 = -6. Поскольку 5 делит на -6 без остатка, то 17 ≡ 23 (mod 5).

### Кольцо

Кольцом K называется непустое множество элементов, на котором определены две арифметические операции сложения + и умножения ·, относительно которых выполняются следующие формулы:

* a + b = a + b
* a · b = a · b

Например, в кольце Z 5 мы можем вычислить произведение двух элементов: 2 · 3 = 6 ≡ 1 (mod 5).
