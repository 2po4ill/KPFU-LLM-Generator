# Лабораторная работа: RSA

**Цель работы**
Ознакомиться с алгоритмом RSA и его основными свойствами.

**Краткая теоретическая база**

Системы шифрования с открытым ключом представляют собой класс криптографических методов, в которых для шифрования и расшифрования используются совершенно разные ключи. Ключ шифрования (открытый ключ) разрешается передавать любому пользователю системы, а секретный ключ используется только для восстановления исходного текста.

Модулярная арифметика — это математическая теория, которая позволяет выполнять арифметические операции над целыми числами по модулю некоторого числа. Для любых a и b выполняется формула a + b = a + b (то же для других перечисленных выше операций), поэтому операции над вычетами выполняются как над обычными числами.

**Необходимые данные/инструменты**

* Основные понятия модулярной арифметики
* Алгоритм RSA

**Пошаговое выполнение**

1. Ознакомьтесь с основными свойствами систем шифрования с открытым ключом и алгоритмом RSA.
2. Понаблюдайте за тем, как модулярная арифметика позволяет выполнять арифметические операции над целыми числами по модулю некоторого числа.
3. Ознакомьтесь с основными этапами работы алгоритма RSA:
	* Генерация ключей: открытый ключ и секретный ключ.
	* Шифрование: преобразование исходного текста в шифротекст с помощью открытого ключа.
	* Расшифрование: восстановление исходного текста из шифротекста с помощью секретного ключа.

**Ожидаемые результаты**

* Описать основные этапы работы алгоритма RSA.
