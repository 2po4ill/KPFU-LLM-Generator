# Лабораторная работа: RSA

**Цель работы**
Ознакомиться с алгоритмом RSA и его основными свойствами.

**Краткая теоретическая база**

Системы шифрования с открытым ключом представляют собой класс криптографических методов, в которых для шифрования и расшифрования используются совершенно разные ключи. Ключ шифрования (открытый ключ) разрешается передавать любому пользователю системы, а секретный ключ используется только для восстановления исходного текста.

Модулярная арифметика является основой алгоритма RSA. В частности, рассматриваются целые числа и их сравнение по модулю натурального числа. Отношение сравнения по модулю обладает свойствами рефлексивности, симметричности и транзитивности.

**Необходимые данные/инструменты**

* Основные понятия модулярной арифметики
* Определения ключей шифрования и расшифрования в системах с открытым ключом

**Пошаговое выполнение**

1. Ознакомьтесь с основными свойствами модулярной арифметики.
2. Понимайте, как система RSA использует открытый и секретный ключи для шифрования и расшифрования текста.
3. Приведите примеры использования алгоритма RSA.

**Ожидаемые результаты**

* Ознакомление с основными свойствами модулярной арифметики
* Понимание принципа работы системы RSA
* Умение применять алгоритм RSA для шифрования и расшифрования текстов

**Критерии оценивания**

* Правильность понимания основных свойств модулярной арифметики
* Правильность применения принципов работы системы RSA
* Качество примера использования алгоритма RSA

**Типичные ошибки**

* Неправильное применение свойств модулярной арифметики
* Неправильное понимание принципа работы системы RSA
* Недостаточная ясность в представлении примера использования алгоритма RSA
