# Лабораторная работа: RSA

**Цель работы**
Ознакомиться с алгоритмом RSA и его основными особенностями.

**Краткая теоретическая база**

Системы шифрования с открытым ключом представляют собой класс шифров, в которых для шифрования и расшифрования используются совершенно разные ключи. Ключ шифрования (публичный ключ) разрешается передавать любому пользователю системы, а секретный ключ используется только для восстановления исходного текста.

Модулярная арифметика является основой алгоритма RSA. В частности, мы рассматриваем отношения сравнения по модулю натурального числа, которые обладают свойствами рефлексивности, симметричности и транзитивности.

**Необходимые данные/инструменты**

* Публичный ключ (e) и секретный ключ (d)
* Число p – простое число
* Число n = p \* q, где q – еще одно простое число

**Пошаговое выполнение**

1. **Шифрование**: для шифрования исходного текста t мы вычисляем c ≡ m^e (mod n), где m — исходный текст.
2. **Расшифрование**: для расшифрования шифротекста c мы вычисляем m ≡ c^d (mod n).

**Ожидаемые результаты**

* Шифрованный текст c должен быть нечитаемым и иметь вид c ∈ {0, 1, ..., n-1}.
* Расшифрованный текст m должен совпадать с исходным текстом t.

**Критерии оценивания**

* Правильность шифрования и расшифрования
* Скорость выполнения алгоритма

**Типичные ошибки**

* Неправильное использование публичного или секретного ключа.
* Неправильная реализация модулярной арифметики.

Примечание: данная лабораторная работа предназначена для ознакомления с основными особенностями алгоритма RSA и не предполагает реального использования этого алгоритма в практических приложениях.
