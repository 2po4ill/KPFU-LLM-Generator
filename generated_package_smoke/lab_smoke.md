# Лабораторная работа: Основные вопросы защиты информации.

# Цель работы
Целью этой работы является понимание и применение различных алгоритмов, используемых в криптографии для обеспечения безопасности данных. В частности, мы будем изучать различные методы факторизации чисел, которые являются важнейшим компонентом алгоритма RSA.

# Краткая теоретическая база
Алгоритм RSA является одним из наиболее широко используемых методов шифрования в Интернете. Он основан на принципе факторизации чисел и использует большие целые числа для обеспечения безопасности данных. В основе алгоритма лежат три основных компонента: открытый ключ, закрытый ключ и модуль.

*   Открытый ключ используется для шифрования сообщений, а закрытый ключ — для расшифровки.
*   Модуль является большим целым числом, которое делится на два других числа (простые множители). Эти простые множители используются для расчета открытого и закрытого ключей.

# Необходимые данные/инструменты
Для выполнения этой работы нам потребуется следующая информация:

*   Вещественные числа p и q, которые являются простыми числами.
*   Нечетное целое число e такое, что 1 < e < (p - 1)(q - 1).
*   Число d такое, что д = е^(-1) по модулю (p-1)(q-1).

# Пошаговое выполнение
Чтобы факторизовать число n, мы можем использовать следующие шаги:

1.  Найдите простые множители p и q.
2.  Рассчитайте значение e как нечетное целое число такое, что 1 < e < (p - 1)(q - 1).
3.  Рассчитайте значение d как число такое, что д = е^(-1) по модулю (p-1)(q-1).

# Ожидаемые результаты
Ожидаемым результатом этой работы является факторизация числа n на простые множители p и q.

# Критерии оценивания
Работа будет оцениваться по следующим критериям:

*   Правильность факторизации числа n.
*   Правильность расчета открытого ключа e и закрытого ключа d.
*   Правильность использования модуля n для обеспечения безопасности данных.

# Типичные ошибки
Типичными ошибками при выполнении этой работы могут быть:

*   Неправильная факторизация числа n.
*   Неправильный расчет открытого ключа e и закрытого ключа d.
*   Неправильное использование модуля n для обеспечения безопасности данных.
