# Лабораторная работа: RSA

**Цель работы**
Ознакомиться с основными принципами и алгоритмом системы шифрования RSA.

**Краткая теоретическая база**

Система шифрования RSA относится к системам шифрования с открытым ключом. Для шифрования и расшифрования используются совершенно разные ключи: открытый (public) и секретный (private). Открытый ключ разрешается передавать любому пользователю системы, не задумываясь о безопасности.

**Необходимые данные/инструменты**

* Понимание модулярной арифметики
* Понимание концепции вычетов по модулю

**Пошаговое выполнение**

1. **Описание алгоритма RSA**: Система шифрования RSA основана на использовании сложения и умножения в кольце вычетов по модулю n.
2. **Будущие шаги:**
	* Описать процесс построения открытого ключа (public key) и секретного ключа (private key).
	* Описать процесс шифрования и расшифрования текста с помощью ключей.

**Ожидаемые результаты**

После выполнения работы студент должен уметь:

* Описать основные принципы системы шифрования RSA.
* Описать процесс построения открытого и секретного ключей.
* Описать процесс шифрования и расшифрования текста с помощью ключей.

**Критерии оценивания**

* Правильность понимания основных принципов системы шифрования RSA (20 баллов).
* Правильность описания процесса построения открытого и секретного ключей (30 баллов).
* Правильность описания процесса шифрования и расшифрования текста с помощью ключей (30 баллов).

**Типичные ошибки**

* Неправильное понимание концепции вычетов по модулю.
* Неправильное описание процесса построения открытого и секретного ключей.
* Неправильное описание процесса шифрования и расшифрования текста с помощью ключей.
