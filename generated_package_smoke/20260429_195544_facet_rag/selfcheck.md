**Пояснения**

* Система RSA — это система шифрования с открытым ключом, которая использует одновременно и секретный, и открытый ключ.
* Открытый ключ используется для шифрования, а секретный ключ используется для восстановления исходного текста.
* Модулярная арифметика — это тип арифметики, который работает с остатками при делении на определенное число.
* Вычет в модулярной арифметике — это число, которое делится на определенное число без остатка.
