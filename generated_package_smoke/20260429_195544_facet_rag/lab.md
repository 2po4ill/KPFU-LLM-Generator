# Лабораторная работа: RSA

**Цель работы**
Ознакомиться с алгоритмом RSA и его основными свойствами.

**Краткая теоретическая база**

Системы шифрования с открытым ключом представляют собой методы защиты данных, в которых для шифрования и расшифрования используются совершенно разные ключи. Ключ шифрования (публичный ключ) разрешается передавать любому пользователю системы, а секретный ключ используется только для восстановления исходного текста.

Модулярная арифметика является основой алгоритма RSA. В модульной арифметике числа сравниваются по модулю некоторого натурального числа p. Отношение сравнения по модулю обладает свойствами рефлексивности, симметричности и транзитивности.

**Необходимые данные/инструменты**

* Публичный ключ (e)
* Секретный ключ (d)
* Число n (произведение двух простых чисел p и q)

**Пошаговое выполнение**

1. **Шифрование**: для шифрования исходного текста m используется публичный ключ e и формула c ≡ m^e (mod n), где c — шифротекст.
2. **Расшифрование**: для расшифрования шифротекста c используется секретный ключ d и формула m ≡ c^d (mod n).

**Ожидаемые результаты**

* Шифротекст c, который не может быть восстановлен без секретного ключа d.
* Восстановленный исходный текст m.

**Критерии оценивания**

* Правильность расчетов шифрования и расшифрования.
* Использование правильных формул для шифрования и расшифрования.
* Правильность использования публичного и секретного ключей.

**Типичные ошибки**

* Неправильное использование публичного или секретного ключа.
* Неправильная формула для шифрования или расшифрования.
* Неправильный расчет шифротекста или восстановленного исходного текста.
