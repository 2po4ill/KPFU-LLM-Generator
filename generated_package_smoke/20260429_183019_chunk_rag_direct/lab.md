# Лабораторная работа: RSA

**Цель работы**
Ознакомиться с алгоритмом RSA и его основными принципами.

**Краткая теоретическая база**

Системы шифрования с открытым ключом позволяют использовать разные ключи для шифрования и расшифрования текстов. Ключ шифрования, используемый для преобразования исходного текста в шифротекст, разрешается передавать любому пользователю системы, не задумываясь о безопасности.

Модулярная арифметика является основой систем шифрования с открытым ключом. Вычеты по модулю числа натурального n > 0 содержат ровно n элементов и могут выполнять арифметические операции сложения, вычитания, умножения и возведения в степень.

**Необходимые данные/инструменты**

* Понимание модулярной арифметики
* Понимание систем шифрования с открытым ключом

**Пошаговое выполнение**

1. Ознакомьтесь с алгоритмом RSA и его основными принципами.
2. Поняйте, как работает система шифрования с открытым ключом.
3. Поняйте, что такое модулярная арифметика и ее свойства.

**Ожидаемые результаты**

* Понимание алгоритма RSA и его основные принципы
* Понимание системы шифрования с открытым ключом
* Понимание модулярной арифметики

**Критерии оценивания**

* Правильность понимания алгоритма RSA и его основных принципов
* Правильность понимания системы шифрования с открытым ключом
* Правильность понимания модулярной арифметики

**Типичные ошибки**

* Неправильное понимание системы шифрования с открытым ключом
