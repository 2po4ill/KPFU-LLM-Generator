# RSA

RSA — один из краеугольных алгоритмов публично‑ключевой криптографии, позволяющий безопасно передавать конфиденциальные данные и проверять подлинность сообщений в открытых сетях. Его надёжность основана на сложности факторизации больших целых чисел, что делает невозможным восстановление закрытого ключа из публичного без значительных вычислительных ресурсов. При генерации пары ключей используется набор математических инструментов, обеспечивающих быстрые и корректные операции в кольце вычетов. Благодаря этой конструкции RSA нашёл широкое применение в протоколах TLS/SSL, цифровой подписи и защите электронных транзакций, становясь фундаментом современной защищённой коммуникации.

Алгоритмы, которые часто применяются при работе с RSA, решают базовые числовые задачи.  

**Алгоритм Евклида** позволяет находить наибольший общий делитель (НОД) двух целых чисел. Если `a > b`, то `gcd(a, b) = gcd(b, a mod b)`. Процесс повторяется, пока остаток не станет нулём; последний ненулевой делитель и есть НОД. Этот метод широко используется в криптографии и теории чисел.  

**Простые числа** – числа, имеющие ровно два делителя: 1 и себя. Любое целое число раскладывается в произведение простых множителей (основная теорема арифметики). Проверка простоты осуществляется пробными делителями, решетом Эратосфена и более продвинутыми тестами (например, Миллер‑Рабин). Простейшие числа необходимы при выборе параметров RSA.  

**Возведение в степень** часто оптимизируют с помощью «быстрого возведения в степень» (binary exponentiation). Алгоритм использует двоичное представление показателя и требует `O(log n)` умножений, что делает его пригодным для модульного возведения в степень, используемого в RSA.

Эти три инструмента часто комбинируются, обеспечивая эффективность и надёжность дальнейших вычислений.

Процедура создания пары ключей RSA начинается с выбора двух больших простых чисел `p` и `q`. Их произведение  

\[
n = p \cdot q
\]

служит модулем обеих ключей.  

Функция Эйлера для `n` вычисляется как  

\[
\varphi(n) = (p-1)(q-1).
\]

Публичный экспонент `e` выбирается взаимно простым с `\varphi(n)`. На практике часто берут небольшое фиксированное значение, например 65537, поскольку оно упрощает вычисления и сохраняет требуемый уровень безопасности.  

Закрытый экспонент `d` определяется как мультипликативная обратная к `e` по модулю `\varphi(n)`, то есть  

\[
d \cdot e \equiv 1 \pmod{\varphi(n)}.
\]

Итоговая пара ключей выглядит так:  

- Открытый ключ: `(e, n)`  
- Закрытый ключ: `(d, n)`

В кольце вычетов  

\[
\mathbb{Z}_n = \{0,1,\dots ,n-1\}
\]

с обычными операциями сложения и умножения интерес представляет **мультипликативная группа единиц** \(\mathbb{Z}_n^{\times}\). Она состоит из всех элементов, обратимых относительно умножения, то есть тех `a`, для которых существует `b` с условием `ab ≡ 1 (mod n)`.  

Элемент обратим тогда и только тогда, когда \(\gcd(a,n)=1\); поэтому мощность группы равна функции Эйлера \(\varphi(n)\). Например, в \(\mathbb{Z}_{12}\) обратимыми являются 1, 5, 7 и 11, и \(|\mathbb{Z}_{12}^{\times}| = \varphi(12) = 4\).  

Структура \(\mathbb{Z}_n^{\times}\) определяется разложением `n` на простые множители. Если `n = p` – простое, то \(\mathbb{Z}_p^{\times}\) является циклической группой порядка `p‑1`. Для степени простого `p^k` (нечётного `p`) группа также циклическая; для `2^k` при `k ≥ 3` она изоморфна прямому произведению групп порядка 2 и \(2^{k-2}\).  

Общее разложение описывается теоремой о китайском остатке: при  

\[
n = \prod_{i=1}^{s} p_i^{\alpha_i}
\]

имеем  

\[
\mathbb{Z}_n^{\times} \cong \prod_{i=1}^{s} \mathbb{Z}_{p_i^{\alpha_i}}^{\times}.
\]

Это позволяет изучать мультипликативную группу модуля `n` через его простые составляющие.  

Следствие: порядок любого элемента в \(\mathbb{Z}_n^{\times}\) делит \(\varphi(n)\), а значит для любого `a` с \(\gcd(a,n)=1\) выполняется  

\[
a^{\varphi(n)} \equiv 1 \pmod n
\]

(малое теорема Эйлера). При `n` простом получаем более сильный результат – малую теорему Ферма: \(a^{p-1} \equiv 1 \pmod p\).  

Таким образом, мультипликативные группы в кольце вычетов образуют фундаментальную алгебраическую основу, используемую в RSA и других криптографических протоколах.

RSA опирается на выбор двух больших простых чисел, их произведение служит модулем, а взаимно простый с функцией Эйлера показатель образует открытый ключ; закрытый ключ получается как обратный к этому показателю по модулю функции Эйлера, что вычисляется с помощью расширенного алгоритма нахождения НОД. Быстрое возведение в степень позволяет эффективно выполнять операции шифрования и расшифрования, а свойства мультипликативной группы обратимых элементов в кольце вычетов гарантируют, что для любого допустимого основания выполняется соответствующая теорема Эйлера. Таким образом, изученные алгоритмы и алгебраическая структура обеспечивают создание надёжных пар ключей, которые применяются в защите передаваемых данных и в цифровой подписи. Практическая ценность RSA заключается в том, что безопасность её работы основана на сложности факторизации большого произведения простых чисел, что делает её одним из базовых инструментов современной криптографии.
