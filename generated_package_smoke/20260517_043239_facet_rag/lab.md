## 1. Цель работы
- закрепить понятия открытого и закрытого (private) ключей в системах шифрования с открытым ключом;  
- применить свойства сравнения по модулю, кольца вычетов \(Z_n\) и группы обратимых элементов при построении и проверке работы алгоритма RSA;  
- отработать практические навыки работы с алгоритмом Евклида (поиск обратного элемента) и возведения в степень по модулю.

## 2. Краткая теоретическая база  

| Понятие | Формулировка (из учебника) |
|---|---|
| **Система с открытым ключом** | Для шифрования и расшифрования используются совершенно разные ключи. Ключ шифрования (public) передаётся любому пользователю, а закрытый (private) используется только получателем. |
| **Сравнение по модулю** | \(a \equiv b \pmod p\) ⇔ \(p\mid (a-b)\). Отношение рефлексивно, симметрично, транзитивно → эквивалентность. |
| **Кольцо вычетов** | Множество классов вычетов по модулю \(n\) обозначается \(Z_n=\{0,1,\dots ,n-1\}\). На \(Z_n\) определены операции сложения, вычитания, умножения и возведения в степень; при необходимости – деление (если \(n\) простое или степень простого). |
| **Группа по умножению** | Если модуль \(n\) прост, то множество ненулевых элементов \(Z_n^{\*}\) образует коммутативную (абелеву) группу. |
| **Алгоритм Евклида** | Позволяет находить наибольший общий делитель и, как следствие, мультипликативную обратную величину по модулю. |
| **Возведение в степень по модулю** | Операция \(a^k \bmod n\) выполняется в кольце \(Z_n\) и сохраняет свойства ассоциативности и дистрибутивности. |

Эти свойства позволяют построить пару ключей RSA и гарантировать, что шифрование и расшифрование являются обратными операциями.

## 4. Пошаговое выполнение  

### Шаг 1. Выбор простых чисел  
1. Выберите два различных простых числа \(p\) и \(q\) (например, \(p=5,\;q=11\)).  

### Шаг 2. Вычисление модуля \(n\) и функции Эйлера \(\varphi(n)\)  
2. Вычислите \(n = p\cdot q\).  
3. Вычислите \(\varphi(n) = (p-1)(q-1)\). (Эта величина используется в алгоритме Евклида для нахождения обратного элемента.)  

### Шаг 3. Выбор открытого экспонента \(e\)  
4. Выберите целое \(e\) такое, чтобы \(1 < e < \varphi(n)\) и \(\gcd(e,\varphi(n)) = 1\).  
5. Запишите открытый ключ как пару \((e,n)\).  

### Шаг 4. Нахождение закрытого экспонента \(d\) (мультипликативная обратная к \(e\) по модулю \(\varphi(n)\))  
6. С помощью **алгоритма Евклида** найдите \(d\) удовлетворяющее условию  
\[
e\cdot d \equiv 1 \pmod{\varphi(n)} .
\]  
7. Запишите закрытый ключ как пару \((d,n)\).  

### Шаг 5. Шифрование сообщения  
8. Выберите сообщение \(m\) – целое число, удовлетворяющее \(0 \le m < n\) (например, \(m=7\)).  
9. Вычислите шифртекст  
\[
c \equiv m^{\,e} \pmod n .
\]  

### Шаг 6. Расшифрование сообщения  
10. Вычислите  
\[
m' \equiv c^{\,d} \pmod n .
\]  
11. Сравните полученное \(m'\) с исходным \(m\).  

### Шаг 7. Проверка свойств модулярной арифметики  
12. Убедитесь, что полученные результаты удовлетворяют свойствам сравнения по модулю (рефлексивность, симметричность, транзитивность).  
13. Проверьте, что все промежуточные вычисления находятся в кольце \(Z_n\) (результат всегда приводится к диапазону \([0,n-1]\)).  

---

## 5. Ожидаемые результаты  

| Параметр | Пример расчёта |
|---|---|
| \(n\) | \(5 \times 11 = 55\) |
| \(\varphi(n)\) | \((5-1)(11-1)=4 \times 10 = 40\) |
| Выбранный \(e\) | \(e=3\) ( \(\gcd(3,40)=1\) ) |
| Найденный \(d\) | \(d=27\) (поскольку \(3\cdot27=81 \equiv 1 \pmod{40}\)) |
| Открытый ключ | \((e,n) = (3,55)\) |
| Закрытый ключ | \((d,n) = (27,55)\) |
| Шифртекст \(c\) | \(c \equiv 7^{3} \pmod{55}=343 \bmod 55 = 13\) |
| Расшифрованное сообщение \(m'\) | \(m' \equiv 13^{27} \pmod{55}=7\) (совпадает с исходным \(m\)) |

Все операции должны оставаться в пределах кольца \(Z_{55}\) и удовлетворять свойствам сравнения по модулю.
