# RSA

Система RSA представляет собой метод шифрования с открытым ключом, который обеспечивает безопасную передачу данных между пользователями. Этот метод основан на использовании пары ключей: открытого ключа для шифрования и секретного ключа для расшифрования. Открытый ключ можно свободно распространять, а секретный ключ остается конфиденциальным.

Система RSA имеет важное значение в современной информационной безопасности, поскольку обеспечивает надежную защиту данных от несанкционированного доступа. Этот метод широко используется в различных областях, таких как банковские операции, электронная почта и другие сферы, где безопасность передачи данных имеет важное значение.

Система RSA представляет собой сложный алгоритм, который обеспечивает высокую степень безопасности и надежности. Сложность алгоритма делает его практически невозможным для взлома, что делает систему RSA надежной и безопасной методом защиты данных.

Для описания алгоритма RSA введем несколько определений.

Пусть Z обозначает множество целых чисел. Все рассматриваемые в нашем учебнике числа, если не указано особо, принадлежат Z.

Определение 2.1. Говорят, что два целых числа a и b сравнимы по модулю p, записывается, a ≡ b( mod p), если p|(a − b) (разность a − b делится на p без остатка).

Для генерации ключей RSA необходимо выбрать два больших простых числа p и q. Затем вычислить n = pq и φ(n) = (p-1)(q-1). 

Далее выбирается случайное число e такое, что 1 < e < φ(n) и gcd(e,φ(n))=1.

Затем вычисляется d по формуле d ≡ e^(-1) (mod φ(n)), где e^(-1) — обратная степень e по модулю φ(n).

Ключи RSA: открытый ключ — (e,n), секретный ключ — (d,n).

Система RSA относится к системам шифрования с открытым ключом. Для шифрования и расшифрования используются совершенно разные ключи: открытый – public и секретный – private. Ключ шифрования, используемый для преобразования исходного текста в шифротекст, разрешается передавать любому пользователю системы, поэтому этот ключ называется открытым.

Для описания алгоритма RSA введем несколько определений. Пусть Z обозначает множество целых чисел. Определение 2.1 гласит, что два целых числа a и b сравнимы по модулю p, записывается, a ≡ b( mod p), если p|(a − b) (разность a − b делится на p без остатка).

Отношение сравнения по модулю натурального числа обладает следующими свойствами: рефлексивностью, симметричностью и транзитивностью. Значит отношение сравнения по модулю является отношением эквивалентности на множестве целых чисел.

Классы эквивалентности, образованные целыми числами по этому отношению, называются вычетами. Вычет, содержащий число k, обозначается k. Множество классов вычетов по модулю числа натурального n > 0 содержит ровно n элементов.

Над вычетами можно выполнять арифметические операции сложения, вычитания, умножения и возведения в степень. Если число n простое или является некоторой степенью простого числа, то и деление. Для любых a и b выполняется формула a + b = a + b (то же для других перечисленных выше операции).

Множество классов вычетов по модулю n образует структуру, являющуюся кольцом. Кольцом K называется непустое множество элементов, на котором определены две арифметические операции сложения + и умножения ·, относительно которых выполняются следующие формулы:

а) (a + b) + c = a + (b + c);
б) a + b = b + a;
в) (a + b) * c = a * c + b * c;
г) a * (b + c) = a * b + a * c.

Для шифрования и расшифрования в системе RSA используются открытый ключ, который представляет собой произведение двух больших простых чисел p и q, а также секретный ключ, который представляет собой произведение (p-1)*(q-1).

Системы шифрования с открытым ключом характеризуются использованием разных ключей для шифрования и расшифрования данных. Ключ шифрования, также известный как открытый ключ, разрешается передавать любому пользователю системы без ограничений по безопасности. Этот ключ используется для преобразования исходного текста в шифротекст и может быть свободно распространен по различным сетям с открытым доступом.

В противоположность этому секретный ключ, также известный как приватный ключ, используется только для восстановления исходного текста из шифротекста. Он остается конфиденциальным и не передается третьим лицам.

Одним из основных преимуществ систем с открытым ключом является возможность безопасной передачи данных между различными пользователями без необходимости обмена секретным ключом.
