# Лабораторная работа: RSA

**Цель работы**
Ознакомиться с алгоритмом RSA и его основными особенностями.

**Краткая теоретическая база**

Системы шифрования с открытым ключом представляют собой класс криптографических систем, в которых для шифрования и расшифрования используются совершенно разные ключи. Ключ шифрования (открытый ключ) разрешается передавать любому пользователю системы, не задумываясь о безопасности, поэтому этот ключ называется открытым.

**Необходимые данные/инструменты**

* Понимание модулярной арифметики и свойств сравнения по модулю.
* Знания алгоритма RSA.

**Пошаговое выполнение**

1. Ознакомьтесь с основными особенностями систем шифрования с открытым ключом, в частности с алгоритмом RSA.
2. Понаблюдайте за тем, как для шифрования и расшифрования используются совершенно разные ключи.
3. Прочитайте определение модулярной арифметики и свойства сравнения по модулю.
4. Ознакомьтесь с основными свойствами алгоритма RSA.

**Ожидаемые результаты**

* Понимание основных особенностей систем шифрования с открытым ключом, в частности алгоритма RSA.
* Знания модулярной арифметики и свойств сравнения по модулю.
* Понимание основных свойств алгоритма RSA.

**Критерии оценивания**
