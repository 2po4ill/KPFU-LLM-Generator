# Лабораторная работа: RSA

**Лабораторная работа по теме "RSA"**
==============================

### Цель работы

В этом задании вы должны продемонстрировать понимание основ алгоритма RSA и его применения в системах шифрования с открытым ключом.

### Краткая теоретическая база

Система RSA относится к системам шифрования с открытым ключом, где для шифрования и расшифрования используются совершенно разные ключи. Ключ шифрования (публичный ключ) разрешается передавать любому пользователю системы, а секретный ключ используется только для восстановления исходного текста.

### Необходимые данные/инструменты

* Понимание алгоритма RSA и его основных понятий
* Умение выполнять арифметические операции по модулю

### Пошаговое выполнение

1. **Описать ключевые особенности системы шифрования с открытым ключом**:
	* Что такое публичный ключ и секретный ключ?
	* Как они используются для шифрования и расшифрования?
2. **Привести примеры арифметических операций по модулю**:
	* Выполните сложение, вычитание, умножение и возведение в степень по модулю n.
3. **Описать процесс генерации ключей RSA**:
	* Какие числа используются для генерации ключей?
	* Как они связаны между собой?

### Ожидаемые результаты

В результате работы вы должны продемонстрировать понимание основных концепций алгоритма RSA и его применения в системах шифрования с открытым ключом.

### Критерии оценивания

* Правильность описания ключевых особенностей системы шифрования с открытым ключом (20 баллов)
* Правильность примеров арифметических операций по модулю (15 баллов)
* Правильность описания процесса генерации ключей RSA (15 баллов)
* Качество и четкость написания (10 баллов)

### Типичные ошибки

* Неправильное понимание концепции публичного и секретного ключа
* Неправильная выполнение арифметических операций по модулю
* Неправильное описание процесса генерации ключей RSA
