# Лабораторная работа: RSA

**Цель работы**
Ознакомиться с алгоритмом RSA и его основными свойствами.

**Краткая теоретическая база**

Системы шифрования с открытым ключом представляют собой класс криптографических методов, в которых для шифрования и расшифрования используются совершенно разные ключи. Ключ шифрования (open key) разрешается передавать любому пользователю системы, не задумываясь о безопасности, поэтому он называется открытым. В отличие от этого, секретный ключ (private key), используемый для восстановления исходного текста, должен сохраняться в тайне.

Алгоритм RSA относится к системам шифрования с открытым ключом и использует модулярную арифметику для обеспечения безопасности. Модулярная арифметика — это математическая теория, которая изучает свойства целых чисел по модулю натурального числа.

**Необходимые данные/инструменты**

* Понимание основ модулярной арифметики
* Знания о системах шифрования с открытым ключом

**Пошаговое выполнение**

1. **Шаг 1: Ознакомьтесь с алгоритмом RSA**
	* Изучите определения и свойства модулярной арифметики.
	* Понимайте, как алгоритм RSA использует модулярную арифметику для обеспечения безопасности.
2. **Шаг 2: Ознакомьтесь с ключами шифрования**
	* Изучите разницу между открытым и секретным ключами.
	* Понимайте, как открытый ключ используется для шифрования, а секретный ключ — для расшифрования.

**Ожидаемые результаты**

После выполнения работы вы должны быть в состоянии:

* Описать основные свойства модулярной арифметики
* Описать алгоритм RSA и его основные компоненты (открытый и секретный ключи)
* Понимать, как алгоритм RSA обеспечивает безопасность

**Критерии оценивания**

* Правильность понимания модулярной арифметики
* Правильность описания алгоритма RSA и его компонентов
* Правильность понимания безопасности алгоритма RSA

**Типичные ошибки**

* Неправильное понимание модулярной арифметики
* Неправильное описание алгоритма RSA и его компонентов
* Неправильное понимание безопасности алгоритма RSA
