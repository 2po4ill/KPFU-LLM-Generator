**Краткие пояснения**

* Система шифрования с открытым ключом — это система, в которой используются два разных ключа: открытый и секретный.
* Модулярная арифметика — это арифметика с использованием остатков при делении на определенное число.
* Вычет по модулю n — это класс эквивалентности целых чисел по отношению сравнения по модулю n.
* Кольцо в контексте модулярной арифметики — это непустое множество элементов, на котором определены две арифметические операции сложения и умножения.
* Секретный ключ — это ключ расшифрования, используемый для восстановления исходного текста.
