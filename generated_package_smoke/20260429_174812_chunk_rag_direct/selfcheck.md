**Краткие пояснения**

* Система шифрования с открытым ключом использует два разных ключа: открытый и секретный.
* Модулярная арифметика — это область математики, которая изучает свойства целых чисел по модулю натурального числа.
* Вычет по модулю n — это класс эквивалентности, образованный целыми числами по отношению сравнения по модулю n.
* Кольцо — это структура, образованная множеством классов вычетов по модулю n.
* Дистрибутивность — это свойство кольца, которое гласит, что для любых a и b выполняется формула a · (b + c) = a · b + a · c.
