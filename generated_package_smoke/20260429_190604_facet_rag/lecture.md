# RSA

**Введение в систему шифрования RSA**

Система шифрования с открытым ключом (Public-Key Cryptography) является важнейшим направлением в криптографии, позволяя обеспечивать безопасность данных при передаче и хранении. В этой теме мы рассмотрим одну из наиболее широко используемых систем шифрования с открытым ключом — RSA.

**Основные концепции**

Система шифрования с открытым ключом основана на использовании двух разных ключей: открытого (public) и закрытого (private). Открытый ключ используется для шифрования данных, а закрытый ключ — для расшифровки. Это достигается за счет использования сложных математических операций, таких как модулярная арифметика.

Модулярная арифметика является фундаментальной концепцией в криптографии и позволяет выполнять арифметические операции с целыми числами по модулю некоторого натурального числа. Это обеспечивает безопасность данных при передаче, поскольку сложные математические операции делают невозможным обратное расчет исходных данных.

### Системы шифрования с открытым ключом

Система шифрования с открытым ключом — это тип криптографических систем, в которых для шифрования и расшифрования используются совершенно разные ключи.

#### Модулярная арифметика

Модулярная арифметика — это область математики, которая изучает операции с целыми числами по модулю некоторого натурального числа. Пусть p — натуральное число. Говорят, что два целых числа a и b сравнимы по модулю p, записывается, a ≡ b( mod p), если p|(a − b) (разность a − b делится на p без остатка). Отношение сравнения по модулю натурального числа обладает следующими свойствами:

1. Рефлексивность: a ≡ a( mod p).
2. Симметричность: a ≡ b( mod p) → b ≡ a( mod p).
3. Транзитивность: a ≡ b( mod p)&b ≡ c( mod p) → a ≡ c( mod p).

Отношение сравнения по модулю натурального числа обладает следующими свойствами:

1. Рефлексивность: a ≡ a( mod p).
2. Симметричность: a ≡ b( mod p) → b ≡ a( mod p).
3. Транзитивность: a ≡ b( mod p)&b ≡ c( mod p) → a ≡ c( mod p).

Значит отношение сравнения по модулю является отношением эквивалентности на множестве целых чисел.

Классы эквивалентности, образованные целыми числами по этому отношению, называются вычетами. Вычет, содержащий число k, обозначается k.

Множество классов вычетов по модулю числа натурального n > 0 содержит ровно n элементов, записываемых как Z = {0, 1, ...n − 1}.

Над вычетами можно выполнять арифметические операции сложения, вычитания, умножения и возведения в степень, а если число n простое или является некоторой степенью простого числа, то и деление.

Будем обозначать множество вычетов по модулю n через Z .

Отметим, что для любых a и b выполняется формула a + b = a + b (то же для других перечисленных выше операции), поэтому операции над вычетами выполняются как над обычными числами, приводя результат к значению, принадлежащему интервалу [0, n−1] путем выполнения операции вычисления остатка от деления результата на число n (т.е. операции, обозначаемой mod n).

Например, в множестве Z 2 · 5 = 10 = 3(mod7). Чаще пишут просто: 2 · 5 = 3( mod 7).

Множество классов вычетов по модулю n образует структуру, являющуюся кольцом. Кольцом K называется непустое множество элементов, на котором определены две арифметические операции сложения + и умножения ·, относительно которых выполняются следующие формулы:

1. Ассоциативность: (a + b) + c = a + (b + c).
2. Дистрибутивность: a × (b + c) = a × b + a × c.
3. Нулевой элемент: существует такой элемент 0, что для любого a выполняется a + 0 = a.
4. Унитарный элемент: существует такой элемент 1, что для любого a выполняется a × 1 = a.

Кольцо K называется полем, если на нем определена еще одна арифметическая операция деления, относительно которой выполняются следующие формулы:

1. Ассоциативность: (a ÷ b) ÷ c = a ÷ (b ÷ c).
2. Дистрибутивность: a × (b ÷ c) = (a × b) ÷ c.
3. Нулевой элемент: существует такой элемент 0, что для любого a выполняется a ÷ 0 = 0.
4. Унитарный элемент: существует такой элемент 1, что для любого a выполняется a ÷ 1 = a.

**Заключение-конспект**

Система шифрования с открытым ключом — это тип криптографических систем, в которых для шифрования и расшифрования используются совершенно разные ключи. Модулярная арифметика является фундаментальной концепцией в этой области, позволяя выполнять арифметические операции над целыми числами по модулю некоторого натурального числа.

Алгоритм RSA — это один из наиболее широко используемых алгоритмов шифрования с открытым ключом. Он основан на использовании сложения и умножения в кольцах вычетов по модулю простых чисел. Для построения открытого и закрытого ключей необходимо выбрать два больших простых числа p и q, а затем вычислить n = pq и φ(n) = (p-1)(q-1).

Практическая ценность изученного материала заключается в обеспечении безопасности данных при передаче через сеть. Системы шифрования с открытым ключом позволяют гарантировать конфиденциальность и целостность данных, что особенно важно для онлайн-банкинга, электронной почты и других облачных сервисов.
