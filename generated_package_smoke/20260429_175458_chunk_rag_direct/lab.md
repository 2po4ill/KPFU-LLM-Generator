# Лабораторная работа: RSA

**Цель работы**
Ознакомиться с алгоритмом RSA и его основными понятиями.

**Краткая теоретическая база**

Системы шифрования с открытым ключом позволяют использовать разные ключи для шифрования и расшифрования. Ключ шифрования (публичный) можно свободно передавать, а секретный ключ используется только для расшифрования.

Модулярная арифметика — это область математики, которая работает с целыми числами по модулю другого числа. Для двух целых чисел a и b говорят, что они сравнимы по модулю p (a ≡ b(mod p)), если p делит их разность (p|(a − b)).

**Необходимые данные/инструменты**

* Понимание модулярной арифметики
* Понимание системы шифрования с открытым ключом

**Пошаговое выполнение**

1. Ознакомьтесь с алгоритмом RSA и его основными понятиями.
2. Изучите определения и свойства модулярной арифметики.
3. Понимайте, как система шифрования с открытым ключом работает в сравнении с классическими системами шифрования.

**Ожидаемые результаты**

* Понимание алгоритма RSA и его основных понятий
* Понимание модулярной арифметики и ее свойств
* Понимание различий между системой шифрования с открытым ключом и классическими системами шифрования

**Критерии оценивания**

* Правильность понимания алгоритма RSA и его основных понятий (40%)
* Правильность понимания модулярной арифметики и ее свойств (30%)
* Правильность понимания различий между системой шифрования с открытым ключом и классическими системами шифрования (30%)

**Типичные ошибки**

* Неправильное понимание алгоритма RSA
* Неправильное понимание модулярной арифметики
* Неправильное понимание различий между системой шифрования с открытым ключом и классическими системами шифрования.
