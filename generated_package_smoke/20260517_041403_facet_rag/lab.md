# Лабораторная работа: RSA

**Цель работы**
Оценка понимания алгоритма RSA и его особенностей.

**Краткая теоретическая база**

Алгоритм RSA относится к системам шифрования с открытым ключом. Для шифрования и расшифрования используются совершенно разные ключи: открытый (public) и секретный (private). Открытый ключ разрешается передавать любому пользователю системы, а секретный ключ используется только для восстановления исходного текста.

Модулярная арифметика является основой алгоритма RSA. Пусть Z обозначает множество целых чисел. Для двух целых чисел a и b говорят, что они сравнимы по модулю p (a ≡ b(mod p)), если p|(a − b). Отношение сравнения по модулю обладает свойствами рефлексивности, симметричности и транзитивности.

**Необходимые данные/инструменты**

* Пара простых чисел p и q
* Открытый ключ (e) и секретный ключ (d)
* Исходный текст

**Пошаговое выполнение**

1. Генерируйте пару простых чисел p и q.
2. Вычислите n = p \* q.
3. Выберите открытый ключ e, который удовлетворяет условию 1 < e < (p-1) \* (q-1).
4. Вычислите секретный ключ d по формуле d = e^(-1) mod ((p-1) \* (q-1)).
5. Шифруйте исходный текст с помощью открытого ключа e и модуля n.
6. Расшифруйте шифротекст с помощью секретного ключа d и модуля n.

**Ожидаемые результаты**

* Правильно зашифрованный шифротекст
* Правильно расшифрованный исходный текст

**Критерии оценивания**

* Правильность понимания алгоритма RSA и его особенностей
* Правильность выполнения шагов по генерации ключей и шифрования/расшифрования
* Правильность результатов шифрования и расширения

**Типичные ошибки**

* Неправильное понимание алгоритма RSA и его особенностей
* Неправильное выполнение шагов по генерации ключей и шифрования/расшифрования
* Неправильность результатов шифрования и расширения
