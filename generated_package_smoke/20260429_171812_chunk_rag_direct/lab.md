# Лабораторная работа: RSA

**Лабораторная работа по теме "RSA"**
==============================

### Цель работы

Ознакомиться с алгоритмом RSA и его основными свойствами, а также научиться применять этот алгоритм для шифрования и расшифрования текстов.

### Краткая теоретическая база

Система RSA относится к системам шифрования с открытым ключом. Для шифрования и расшифрования используются совершенно разные ключи: открытый (public) и секретный (private). Открытый ключ разрешается передавать любому пользователю системы, а секретный ключ используется только для восстановления исходного текста.

Множество классов вычетов по модулю числа натурального n образует структуру, являющуюся кольцом. Кольцо Z является коммутативной группой по сложению и имеет обратимое умножение.

### Необходимые данные/инструменты

* Пара простых чисел p и q
* Открытый ключ (e)
* Секретный ключ (d)

### Пошаговое выполнение

1. **Шифрование**: для шифрования текста T с помощью открытого ключа e и модуля n вычисляем c ≡ T^e (mod n).
2. **Расшифрование**: для расшифрования шифротекста c с помощью секретного ключа d и модуля n вычисляем T ≡ c^d (mod n).

После выполнения лабораторной работы вы должны быть в состоянии:

* Понять основные свойства системы RSA, такие как безопасность и эффективность

* Неправильное понимание основных свойств системы RSA
