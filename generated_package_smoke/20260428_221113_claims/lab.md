# Лабораторная работа: Основные вопросы защиты информации.

**Цель работы**
Ознакомиться с основными вопросами защиты информации, в частности с системой шифрования RSA и ее ключевыми понятиями.

**Краткая теоретическая база**

Система шифрования RSA относится к системам шифрования с открытым ключом. Для шифрования и расшифрования используются совершенно разные ключи: открытый ключ (public key) и закрытый ключ (private key). Открытый ключ используется для шифрования, а закрытый ключ — для расшифрования.

**Необходимые данные/инструменты**

* Понимание основных понятий защиты информации
* Знания по алгебре и теории чисел

**Пошаговое выполнение**

1. **Шифрование**: Для шифрования текстовой строки M необходимо:
	* Разобрать текст на отдельные символы.
	* Заменить последовательность символов последовательностью их кодов (например, в стандартной кодировке Win 1251).
	* Зашифровать последовательность, заменяя каждый код c на шифрокод по формуле: h = enc(c) = ce mod n.
2. **Расшифрование**: Для расшифрования шифростроки enc(M) необходимо:
	* Расшифровать последовательность, заменяя каждый шифрокод h на код c = dec(h), вычисляемый по формуле: c = hd mod n.
	* Заменить коды c на символы текста, восстанавливая сообщение.

**Ожидаемые результаты**

После выполнения работы студент должен уметь:

* Описать основные понятия защиты информации
* Понимать принципы шифрования и расшифрования в системе RSA
* Выполнять шаги шифрования и расшифрования

**Критерии оценивания**

* Правильность понимания основных понятий защиты информации
* Правильность выполнения шагов шифрования и расшифрования
* Качество описания принципов шифрования и расшифрования в системе RSA

**Типичные ошибки**

* Неправильное понимание ключевых понятий защиты информации
* Неправильное выполнение шагов шифрования и расшифрования
* Недостаточная ясность описания принципов шифрования и расшифрования в системе RSA
