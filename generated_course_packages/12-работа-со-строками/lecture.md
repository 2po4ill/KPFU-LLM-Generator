# Работа со строками

### Введение-конспект: Работа со строками в Python

**Важность темы:** Строки — фундаментальный тип данных, используемый для представления текстовой информации. Эффективная работа с ними необходима для решения большинства прикладных задач: от обработки пользовательского ввода и анализа данных до генерации отчетов и веб-разработки.

**Практическое применение:** Навыки работы со строками применяются повсеместно: проверка и очистка данных, парсинг файлов, форматирование вывода, построение SQL-запросов и HTML-шаблонов.

**Ключевые концепции, раскрываемые в конспекте:**

1.  **Основы:** Строковые литералы (одинарные, двойные, тройные кавычки), экранирование, неформатированные (raw) строки. Неизменяемость строк: любая операция создает новый объект.
2.  **Доступ к данным:** Индексация (доступ к символу по индексу, в т.ч. отрицательному) и срезы (извлечение подстроки).
3.  **Операции:** Конкатенация (объединение строк оператором `+`), повторение, проверка вхождения (`in`), длина (`len()`).
4.  **Методы:** Основные методы для преобразования и анализа: `find()`, `replace()`, `split()`, `join()`, `strip()`, `startswith()/endswith()`, `upper()/lower()`.
5.  **Форматирование:** Способы подстановки значений в шаблоны: оператор `%`, метод `str.format()` и f-строки (будут рассмотрены отдельно). Преобразование типов: `str()`, `int()`.

Конспект систематизирует эти концепции, предоставляя базовый инструментарий для решения типовых задач.

### Строковые литералы
<!-- CONCEPT_ORIGIN: concept="Строковые литералы"; pages=[207,208,210,211,213]; book="Book izuchaem_python_pkg"; claims=["В Python строковые литералы можно записывать разными способами.", "Строки в апострофах и в кавычках — это одно и то же.", "Строковые литералы можно заключать как в апострофы, так и в кавычки.", "Две формы представления строк (апострофы и кавычки) ничем не отличаются и возвращают объект того же типа.", "Причина наличия двух вариантов записи строк — позволить вставлять в литералы символы кавычек и апострофов без обратного слеша.", "Можно вставлять апострофы в строки, заключённые в кавычки, и наоборот."] -->
Строковые литералы в Python — это последовательности символов, заключенные в кавычки. Существует два основных способа их записи: с использованием одинарных кавычек (апострофов, `'`) и двойных кавычек (`"`). Оба способа эквивалентны и создают объекты одного и того же типа — строки (`str`).

Наличие двух вариантов записи обусловлено практической необходимостью: это позволяет включать в строку символы кавычек без использования экранирования обратным слешем (`\`). Например, если строка содержит апостроф, её удобнее заключить в двойные кавычки, и наоборот.

Примеры:
- `'Это строка в апострофах'`
- `"Это строка в кавычках"`
- `"Внутри есть 'апостроф', и не нужен обратный слеш"`
- `'А здесь "кавычки" внутри строки'`

Без использования альтернативных кавычек пришлось бы экранировать символы: `'Внутри есть \'апостроф\', нужен обратный слеш'`. Таким образом, две формы записи повышают читаемость кода.

### Конкатенация
<!-- CONCEPT_ORIGIN: concept="Конкатенация"; pages=[208,211,217,226,229]; book="Book izuchaem_python_pkg"; claims=["Для работы со строками поддерживается операция конкатенации (объединения строк).", "Операция S1 + S2 является конкатенацией.", "Python автоматически объединяет последовательности строковых литералов внутри выражения.", "Можно добавить оператор + между строковыми литералами для явного вызова операции конкатенации.", "Строки можно объединять с помощью оператора конкатенации +.", "Операция сложения двух строковых объектов создает новый строковый объект, объединяющий содержимое операндов.", "Чтобы изменить строку, можно создать новую строку с помощью операции конкатенации.", "Операция конкатенации создает новую строку.", "Пример конкатенации: S = S + 'SPAM!'.", "Пример изменения строки с помощью извлечения подстроки и конкатенации: S = S[:3] + 'xx' + S[5:]."] -->
Конкатенация — это операция объединения строк. В Python для неё используется оператор `+`. При выполнении операции `S1 + S2` создаётся новый строковый объект, содержащий содержимое первой строки, за которым следует содержимое второй строки. Исходные строки при этом не изменяются, так как строки в Python являются неизменяемыми (immutable) объектами.

Python также поддерживает автоматическую конкатенацию последовательных строковых литералов, записанных рядом (разделённых только пробелами или переносами строк), что удобно для форматирования длинного текста.

Для изменения существующей строковой переменной необходимо явно создать новую строку через конкатенацию и присвоить результат обратно переменной.

Примеры:
- Явная конкатенация: `"Привет, " + "мир!"` → `"Привет, мир!"`
- Автоматическая конкатенация литералов:
  ```python
  text = ("Это очень длинная строка, "
          "которую удобно разбить "
          "на несколько литералов.")
  ```
  Результат: `"Это очень длинная строка, которую удобно разбить на несколько литералов."`
- Изменение строки через создание новой:
  ```python
  S = "spam"
  S = S + "SPAM!"  # Создаётся новая строка "spamSPAM!"
  ```
- Модификация части строки с помощью срезов и конкатенации:
  ```python
  S = "abcdef"
  S = S[:3] + "xx" + S[5:]  # Берутся символы с 0 по 2, добавляется "xx", затем символ с индексом 5 до конца
  ```
  Результат: `"abcxxf"`. Этот метод демонстрирует, как можно "заменить" часть строки, создав новую из фрагментов.

### Индексация
<!-- CONCEPT_ORIGIN: concept="Индексация"; pages=[208,210,219]; book="Book izuchaem_python_pkg"; claims=["Для работы со строками поддерживается выборка символов по индексам (по смещению от начала строки).", "Индексация позволяет получить доступ к элементам строки по смещению.", "S[0] возвращает элемент со смещением 0 от начала строки.", "S[-2] возвращает элемент со смещением 2 от конца строки.", "Отрицательные смещения можно представить как отсчет символов с конца строки.", "Положительные смещения отсчитываются от левого конца строки (первый элемент имеет смещение 0).", "Отрицательные смещения отсчитываются от правого конца строки (последний элемент имеет смещение –1).", "При выполнении операций индексации можно использовать любые виды смещений.", "Строковые литералы можно заключать как в апострофы, так и в кавычки.", "Строки в апострофах и в кавычках возвращают объект того же самого типа.", "Две формы представления строк (апострофы и кавычки) ничем не отличаются.", "Наличие двух вариантов позволяет вставлять в литералы символы кавычек и апострофов без использования обратного слеша.", "Можно вставлять апострофы в строки, заключенные в кавычки."] -->
Индексация обеспечивает доступ к отдельным символам строки по их позиции (смещению). Строки поддерживают выборку символов по индексам, где положительные смещения отсчитываются от начала строки (первый символ имеет индекс 0), а отрицательные — от конца (последний символ имеет индекс -1). Например, для строки `S = "Python"`:
- `S[0]` возвращает `'P'` (первый символ).
- `S[-2]` возвращает `'o'` (второй символ с конца).

Отрицательные индексы удобны для доступа к элементам без предварительного вычисления длины строки. Индексация работает с любыми типами смещений, включая комбинации, но каждый индекс должен указывать на существующий символ, иначе возникает ошибка `IndexError`.

Строковые литералы могут быть заключены в апострофы (`'текст'`) или кавычки (`"текст"`), что не влияет на тип результата — оба варианта создают строковый объект. Это позволяет избежать экранирования символов: например, строка `"Don't"` корректно содержит апостроф, а `'Он сказал: "привет"'` — кавычки. Оба формата функционально идентичны и выбираются для удобства записи.

### Срезы
<!-- CONCEPT_ORIGIN: concept="Срезы"; pages=[208,219,222]; book="Book izuchaem_python_pkg"; claims=["Отрицательные смещения можно представить как отсчет символов с конца строки.", "S[1:3] — это пример получения среза для извлечения подстроки.", "Операция получения среза позволяет извлекать целые участки (подстроки) за одно действие.", "Операция получения среза может использоваться для извлечения столбцов данных, обрезания ведущих и завершающих блоков текста.", "При получении среза интерпретатор Python возвращает новый объект, содержащий непрерывную область, определяемую парой смещений.", "Значение смещения слева от двоеточия обозначает левую границу (включительно), а справа — верхнюю границу (она не входит в срез).", "Операция извлечения среза эквивалентна операции индексирования, в которой в качестве индекса используется специальный объект среза.", "'spam'[1:3] и 'spam'[slice(1, 3)] дают одинаковый результат.", "Типичное использование операции получения среза — получить все элементы списка, за исключением первого, например, sys.argv[1:].", "Для работы со строками поддерживается операция выделения подстроки (среза).", "Операция S[i:j] интерпретируется как извлечение подстроки (среза)."] -->
Срезы позволяют извлекать подстроки из строки за одну операцию. Формат среза `S[i:j]` определяет диапазон от индекса `i` (включительно) до `j` (исключительно). Например, для `S = "spam"`:
- `S[1:3]` возвращает `"pa"` (символы с индексами 1 и 2).
- `S[:3]` эквивалентно `S[0:3]` и возвращает `"spa"`.
- `S[1:]` возвращает `"pam"` (от индекса 1 до конца).

Отрицательные индексы в срезах также поддерживаются: `S[-3:-1]` для `"spam"` вернет `"pa"`. Если левая граница опущена, подстрока начинается с начала строки; если правая граница опущена — продолжается до конца. Срезы автоматически обрабатывают индексы за пределами строки, не вызывая ошибок (например, `S[1:10]` для короткой строки вернет подстроку до конца).

Операция среза эквивалентна использованию объекта `slice(i, j)`: выражение `'spam'[1:3]` идентично `'spam'[slice(1, 3)]`. Срезы применяются для обработки данных, например, чтобы исключить первый элемент (как в `sys.argv[1:]` для аргументов командной строки) или обрезать текст. Результат среза — новый строковый объект, исходная строка остается неизменной.

### Методы строк

Строки в Python являются неизменяемыми объектами. Любая операция, модифицирующая строку, создает новый строковый объект, а оригинальная строка остается без изменений. Это фундаментальное свойство распространяется на все строковые методы.

**Ключевые методы и операции:**
*   **Поиск:** Метод `find()` возвращает целочисленное смещение (индекс) первого вхождения подстроки или `-1`, если подстрока не найдена. Оператор `in` выполняет аналогичный поиск, но возвращает булево значение (`True`/`False`), что удобно для проверок в условных выражениях.
    *   Пример: `"Python".find("th")` вернет `2`. `"th" in "Python"` вернет `True`.
*   **Замена:** Метод `replace(old, new[, count])` создает новую строку, в которой все вхождения подстроки `old` заменены на подстроку `new`. Необязательный третий аргумент `count` ограничивает количество замен.
    *   Пример: `"спам-спам-спам".replace("спам", "яйцо", 2)` вернет `"яйцо-яйцо-спам"`.
*   **Разделение и объединение:** Метод `split([sep[, maxsplit]])` преобразует строку в список подстрок, используя переданный разделитель `sep`. По умолчанию разделителем являются любые пробельные символы (пробел, табуляция, новая строка). Разделитель может быть строкой из одного или нескольких символов. Метод `join(iterable)` является обратной операцией: он объединяет элементы итерируемого объекта (например, списка строк) в одну строку, вставляя между ними строку, у которой вызван метод.
    *   Пример: `"a,b,c".split(",")` вернет `['a', 'b', 'c']`. `" - ".join(['a', 'b', 'c'])` вернет `"a - b - c"`.
*   **Удаление пробельных символов:** Метод `rstrip([chars])` возвращает копию строки с удаленными указанными символами в конце строки. По умолчанию удаляются пробельные символы. Для удаления символа новой строки в конце строки предпочтительнее использовать `line.rstrip('\n')`, чем срез `line[:-1]`, так как срез удалит последний символ независимо от его типа, что может привести к ошибке, если строка не заканчивается символом новой строки. Метод же безопасно обработает оба случая.
    *   Пример: Для строки `"text\n"` оба способа дадут `"text"`. Для строки `"text"` срез `[:-1]` вернет `"tex"`, а `"text".rstrip('\n')` корректно вернет `"text"`.

### Форматирование строк

Форматирование строк — это процесс создания новой строки путем подстановки значений объектов (чисел, строк и др.) в строку-шаблон. Исходные строки-шаблоны и подставляемые объекты не изменяются.

**Основные способы:**
1.  **Выражение форматирования с оператором `%`:** Имеет вид `"шаблон с %-спецификаторами" % (значения)`. В строке-шаблоне используются спецификаторы, такие как `%s` для строк, `%d` для целых чисел. Справа от `%` указывается кортеж значений для подстановки.
    *   Пример: `"Меня зовут %s, мне %d лет." % ("Анна", 30)` вернет `"Меня зовут Анна, мне 30 лет."`.
2.  **Метод `str.format()`:** Более современный и гибкий способ. Имеет вид `"шаблон с {}".format(значения)`. Плейсхолдеры `{}` могут содержать номера позиций или именованные аргументы.
    *   Пример: `"a {0} parrot".format("kind")` или `"a {kind} parrot".format(kind="blue")` вернут `"a kind parrot"`.

**Связь с преобразованием типов:**
Для форматирования объекты неявно преобразуются в строки. Явное преобразование также важно:
*   `str(obj)` возвращает "удобочитаемое" строковое представление объекта.
*   `repr(obj)` возвращает формальное строковое представление, часто в виде валидного выражения Python.
*   `int(string)` преобразует строку с цифрами в целое число. Это необходимо, так как оператор `+` не выполняет неявного преобразования: `"123" + 456` вызовет ошибку. Правильно: `int("123") + 456` или `"123" + str(456)`.

Строка в Python является упорядоченной и неизменяемой последовательностью символов. Это означает, что символы располагаются в строгом порядке слева направо, и после создания строки изменить какой-либо ее символ или длину невозможно. Пустая строка записывается как пара кавычек без содержимого (`""` или `''`) и имеет длину, равную нулю.

Длина строки (количество содержащихся в ней символов) определяется с помощью встроенной функции `len()`. Зная длину строки, можно эффективно работать с индексами.

Индексация символов в строке начинается с нуля. Таким образом, последний символ строки имеет индекс не равный длине строки, а на единицу меньше: `len(S) - 1`. Например, в строке `"Python"` длиной 6 символов последний символ `'n'` имеет индекс 5.

Python также поддерживает отрицательную индексацию. Отрицательные индексы отсчитываются справа налево, начиная с -1 для последнего символа. Интерпретатор автоматически преобразует отрицательный индекс в положительный, прибавляя к нему длину строки: `S[-1]` эквивалентно `S[len(S) - 1]`.

Функция `len()` может быть использована для создания проверок, аналогичных методу `str.endswith()`, путем сравнения среза в конце строки с искомым суффиксом.

Примеры:
```python
text = "Привет, мир!"

# Определение длины строки
length = len(text)  # Результат: 12

# Доступ к последнему символу через положительный и отрицательный индекс
last_char_positive = text[11]   # '!'
last_char_negative = text[-1]   # '!'

# Попытка изменения строки приводит к ошибке
# text[0] = 'п'  # Вызовет TypeError: 'str' object does not support item assignment

# Имитация endswith с помощью длины строки и среза
suffix = "мир!"
def custom_endswith(s, suffix):
    return s[len(s) - len(suffix):] == suffix

print(custom_endswith(text, suffix))  # Результат: True
```

Для перебора символов используется цикл `for`, например: `for char in "abc": print(char)` выведет каждый символ на новой строке. Проверить наличие подстроки можно оператором `in`: `'spam' in 'spam and eggs'` вернет `True`.

Строковые литералы можно заключать как в одинарные кавычки (`'...'`), так и в двойные (`"..."`), что позволяет вставлять кавычки одного типа внутрь строк без экранирования: `"It's a string"` или `'Он сказал "привет"'`. Оба варианта создают идентичные строковые объекты. Python автоматически объединяет смежные строковые литералы: `'Hello' ' World'` преобразуется в `'Hello World'`.

Для вставки специальных символов используются экранированные последовательности с обратным слешем (`\`). Например, `\n` представляет символ новой строки, а `\t` — табуляцию. В строковом объекте эти последовательности заменяются одним соответствующим символом. В интерактивной оболочке вывод строк показывает экранированные последовательности, а функция `print` интерпретирует их: `print("Hello\nWorld")` выведет "Hello" и "World" на разных строках. Функция `len` возвращает фактическое количество символов (байтов в ASCII-строках): `len("abc\n")` вернет 4, так как `\n` считается одним символом.

Поскольку строки неизменяемы, любые модификации требуют создания новых объектов. Операции конкатенации (`+`) и метод `replace` возвращают новые строки: `'Hello'.replace('H', 'h')` создаст строку `'hello'`, не изменяя оригинал. Несмотря на кажущуюся неэффективность, Python оптимизирует управление памятью через сборку мусора и повторное использование памяти.

Для сложных преобразований строку можно преобразовать в список символов с помощью `list()`, изменить список, а затем собрать обратно методом `join`:  
```python
s = "строка"
lst = list(s)  # ['с', 'т', 'р', 'о', 'к', 'а']
lst[0] = 'С'
s_new = ''.join(lst)  # 'Строка'
```
Для удаления символов используются срезы и методы. Например, `line[:-1]` удалит последний символ строки, но для удаления символа новой строки предпочтительнее метод `rstrip`, так как он безопасен для строк без `\n` в конце: `'text\n'.rstrip()` вернет `'text'`.

Операция `split` разбивает строку по разделителю: `'a,b,c'.split(',')` даст список `['a', 'b', 'c']`. Обратная операция `join` собирает список в строку: `','.join(['a', 'b', 'c'])` вернет `'a,b,c'`.

Строки и числа неявно не преобразуются: `"123" + 4` вызовет ошибку. Для преобразования используются функции `int("123")` и `str(456)`. Функция `repr` возвращает строковое представление объекта в виде кода: `repr("text")` даст `"'text'"` (включая кавычки).

Метод `S.rstrip()` предназначен для удаления пробельных символов (пробелов, табуляций, символов новой строки) с правого (конечного) края строки. Утверждение из книги о том, что он удаляет ведущие и конечные пробелы, является неточным: для удаления пробелов слева используется `S.lstrip()`, а для удаления с обоих концов — `S.strip()`.

Экранирование символов — важный аспект работы со строками. Чтобы включить в строку сам символ обратного слеша (`\`), его необходимо удвоить (`\\`), так как одиночный слеш начинает escape-последовательность (например, `\n` — новая строка).

Неформатированные (сырые) строки, обозначаемые префиксом `r` или `R` перед открывающей кавычкой, отключают механизм экранирования. Интерпретатор воспринимает обратные слеши внутри них как обычные символы. Это особенно полезно для написания путей к файлам в Windows (`r"C:\new\data.txt"`) и регулярных выражений.

Однако существуют ограничения: неформатированная строка не может заканчиваться единственным обратным слешем (`r"\"` вызовет ошибку), так как он экранирует следующую за ним закрывающую кавычку. Строка также не может заканчиваться нечетным количеством обратных слешей по той же причине. Корректным завершением будет четное количество слешей, например: `r"test\\"`.

Примеры:
```python
s = "  текст с пробелами  "
print(s.strip())  # "текст с пробелами"
print(s.rstrip()) # "  текст с пробелами"

# Экранирование
path = "C:\\new\\file.txt"  # Обычная строка
raw_path = r"C:\new\file.txt" # Неформатированная строка
print(path == raw_path) # True

# Некорректно:
# r"\"  - ошибка
# r"\\\" - ошибка (три слеша)
# Корректно:
r"\\"   # Два слеша в конце
```

В Python 2.6 и 3.0 появился мощный метод `format()` для форматирования строк, а также одноименная встроенная функция `format()`. Встроенная функция `format(value, spec)` предназначена для форматирования одиночных значений и является более компактной альтернативой вызову метода `str.format()` для одного значения. Технически она вызывает специальный метод `__format__` объекта.

Сравнивая метод `format()` с устаревшим оператором `%`, можно отметить, что синтаксис оператора `%` часто выглядит проще для базовых подстановок (например, `"Имя: %s" % name`). Однако метод `format()` предлагает существенные дополнительные возможности:
* Использование именованных аргументов и позиционных подстановок в любом порядке.
* Доступ к элементам коллекций или атрибутам объектов по индексу или имени.
* Расширенные спецификации форматирования, включая двоичное, шестнадцатеричное представление чисел, выравнивание, округление.

Метод `format()` позволяет комбинировать множество сложных подстановок в одной инструкции, что делает код чище и читабельнее по сравнению с цепочкой операций с использованием `%`.

Примеры:
```python
# Встроенная функция format
num = 15
print(format(num, "b")) # '1111' - двоичное представление

# Метод str.format()
# Позиционные и именованные аргументы
text = "Пользователь: {name}, возраст: {age}".format(name="Анна", age=25)
print(text)

# Доступ по индексу и атрибутам (в примере - к элементу списка)
data = ["яблоко", 100]
print("Фрукт: {0[0]}, цена: {0[1]}".format(data))

# Сложное форматирование в одной строке
template = "{user} купил {count:03d} кг по {price:.2f} руб."
result = template.format(user="Петр", count=5, price=123.456)
print(result) # Петр купил 005 кг по 123.46 руб.
```

**ЗАКЛЮЧЕНИЕ-КОНСПЕКТ: Работа со строками**

Изученный материал по работе со строками формирует фундамент для решения подавляющего большинства задач, связанных с обработкой текстовой информации в Python. Ключевой вывод заключается в том, что строки являются **неизменяемыми последовательностями символов**. Это свойство определяет логику всех операций: любая модификация строки (конкатенация, замена, изменение регистра) не изменяет исходный объект, а создает новый.

Практическая ценность рассмотренных концепций чрезвычайно высока:

*   **Базовые операции** (индексация, срезы) позволяют точно извлекать и обрабатывать фрагменты текста, что необходимо при разборе логов, данных из файлов или пользовательского ввода.
*   **Методы строк** (`find()`, `replace()`, `split()`, `join()`, `strip()`) предоставляют мощный и удобный инструментарий для поиска, очистки, разделения и сборки текстовых данных, автоматизируя рутинные задачи.
*   **Способы форматирования** (оператор `%`, метод `format()`) дают возможность гибко создавать строки на основе шаблонов, что критически важно для генерации отчетов, сообщений пользователю и SQL-запросов.
*   **Различные формы строковых литералов** (одинарные/двойные/тройные кавычки, сырые строки) повышают читаемость кода и упрощают работу со строками, содержащими специальные символы, многострочным текстом или документацией.

Умение осознанно выбирать между этими инструментами в зависимости от конкретной задачи — например, использовать срезы для обрезки данных или метод `rstrip()` для безопасного удаления символов, применять `split()`/`join()` для преобразования структур данных — напрямую влияет на эффективность и надежность написанного кода.

Таким образом, уверенное владение работой со строками открывает возможности для автоматизации обработки текста, взаимодействия с файловой системой, предварительной подготовки данных и создания интерфейсов командной строки. Это не просто набор синтаксических правил, а практический навык, который будет постоянно использоваться при дальнейшем изучении Python и решении реальных проблем.
