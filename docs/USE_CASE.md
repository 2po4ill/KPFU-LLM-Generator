## Сценарий (≈15–40 мин с генерацией)

### 1. РПД
1. Загрузите файл РПД (PDF/DOCX).
2. **Разобрать РПД** → появится `rpd_id` и темы.

### 2. Источники
1. **Все PDF** → **Загрузить выбранные PDF**.
2. **Обновить** — статусы `ok`, появятся `book_id`.

### 3. Генерация пакета
1. Выберите тему (например RSA).
2. Настройки:
   - ☑ Презентация (PPTX)
   - ☑ Лабораторная
   - ☑ Самопроверка
3. **Сгенерировать пакет** (долго, 3–10+ мин).

Быстрая проверка UI без PPTX: **Только лекция**.

### 4. Проверка экспертом (human-in-the-loop)
1. Вкладки: **Лекция** / **Лабораторная** / **Самопроверка** — правки в Markdown, предпросмотр справа.
2. Вкладка **Презентация** — карточки слайдов (из `slides.json`).
3. **Сохранить черновик** (или автосохранение через ~1.5 с после правок).
4. **Утвердить для экспорта**.

### 5. Экспорт
| Кнопка | Результат |
|--------|-----------|
| SCORM (.zip) | Moodle/SCORM пакет |
| Всё в PDF (.zip) | `lecture.pdf`, `lab.pdf`, … (если установлен xhtml2pdf) |
| PPTX | презентация |
| Презентация PDF | PDF из слайдов |

## Повторный визит
- Выберите ту же тему — подтянется **черновик** с сервера (`GET /rpd/package-draft`).

## Если PDF не нативный
На сервере: `pip install xhtml2pdf`, перезапустить uvicorn.
